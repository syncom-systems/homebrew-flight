# Homebrew tap for Flight

    brew install syncom-systems/flight/flight

Installs `flight` and the tmux it needs. Supported: macOS on Apple silicon, Linux x86_64. Flight: https://github.com/syncom-systems/flight

The formula's URLs and checksums are those of the release assets (`SHA256SUMS`); each release updates them through a pull request here.
